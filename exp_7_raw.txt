###### 1. Use Case Modelling 

Use case modelling is a technique used to describe how different users interact with a system to achieve specific goals. 

- A use case represents a particular function or service provided by a system. 

- For example, in an Online Food Ordering System, common use cases include: 

   - ¢ Register/Login 

   - « Browse Food 

   - « Search Food 

   - « Place Order 

   - « Make Payment 

   - ¢ Track Order

2. Actors 

An actor is a person, organization, or external system that interacts with the proposed system. 

Examples include: 

- « Student

- « Payment Gateway 

Actors are identified according to the selected problem. 

###### 3. Use Case Diagram 

A use case diagram represents the interaction between actors and system functions. Basic representation: 

Actor — System Function / Use Case 

For example: 

Customer — Login — Select Product — Place Order — Make Payment 

The use case diagram helps developers understand system requirements from the user's point of view. 

4, User Stories 

A user story describes a requirement from the perspective of the user. 

A common format is: 

“As a [user], I want [function], so that [benefit].” 

###### Example: 

As a student, I want to receive notifications about upcoming assignments, so that I can submit them on time.

###### 5. Workflow Design 

A workflow represents the sequence of activities required to complete a task. 

For example, an online food ordering workflow can be represented as: 

Login — Browse Food — Select Food > Add to Cart > Place Order — Make Payment > Order Confirmation — Delivery 

Workflow design helps identify: 

- « Sequence of activities 

- ¢ Decision points 

- « Inputs and outputs 

- « System actions 

- ¢ User actions 

- ¢ Possible errors or alternative paths
